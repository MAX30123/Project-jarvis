<h3 align="center">Overview Jarvis v0.3</h3>

###

<h4 align="center">is a voice-controlled assistant implemented in Python. The application integrates speech recognition and text-to-speech technologies to enable basic voice interaction and execution of system-level commands. The assistant is designed as an educational project demonstrating how to work with audio input, command parsing, and automation in Python.</h4>

###

<h3 align="center">Key Features</h3>

###

<h4 align="center">Speech Processing Speech-to-Text using faster whisper Text-to-Speech using silero Date and Time Functions Provides current system time Provides current system date Birthday recognition with automated greeting File Operations Voice-driven creation of Python project files Application and Web Control Launches local applications via subprocess Opens web resources via default browser, control the system monitor resource processes on a computer</h4>

<h4 align="left">1. System Controls
Volume: "Volume up", "Volume down", "Volume mute", "Volume on".

Screen: "Take a screenshot", "Close all windows" (minimizes everything), "Close tab" (Ctrl+W).

Time & Date: "What time is it?", "What date is today?".

Status: "Check the computer status" (reports CPU load and RAM usage).

Productivity & Work
Work Mode: "To work" or "Jarvis, time to work" (closes games, opens VS Code, and starts music).

Project Creation: "Create project" (Jarvis will then ask for the project name and create a .py file).

Logging Thoughts: "Log this" or "Jarvis, record a thought" (saves your dictated text to _log.txt).

Reminders: "Remind me in [X] minutes [to do something]" (starts a background timer).

Entertainment & Web
Browsing: "Open Google", "Open YouTube".

Search: "Find information" (Jarvis will ask what to search for and open a browser).

Movies: "Turn on the movie" (after providing the name, it searches on HDRezka).

Music: "Play music" or "Turn on the music" (opens a pre-defined YouTube playlist).

News: "Jarvis, what's the news today?" or "Show me the news".

Weather: "What weather" or "What is the weather like now?".

F.R.I.D.A.Y. Protocol (Ollama/LLM Mode)
Activation: "Activate Friday protocol" or "Jarvis, change the protocol for Friday".

Free-form examples while in this mode:

"Friday, how are you feeling today?"

"Suggest a good sci-fi movie."

"Search for the latest space exploration news."

Deactivation: "Return to standard mode" or "Turn off Friday".

Power & Exit
Standby: "Jarvis, be quiet" or "Jarvis, standby" (stops the loop).

Shutdown: "Shut down the computer" (requires a "Yes" or "Confirm" voice response).

</h4>
